# Product Overview

This is a custom embedded operating system/kernel project for STM32 microcontrollers. The project implements a lightweight RTOS-like system with device drivers, kernel services, and application frameworks.

## Key Features

- Multi-target support (STM32F1xx and STM32F4xx series)
- Custom bootloader implementation
- Device driver abstraction layer
- Logging and CLI components
- Modular architecture with clear separation between kernel, drivers, and applications

## Target Hardware

- Primary: STM32F407VET (Cortex-M4)
- Secondary: STM32F103C8T (Cortex-M3)
- ARM Cortex-M architecture focus

## Use Cases

- Embedded system development
- Real-time applications
- Custom firmware for STM32-based projects
- Educational/learning platform for embedded systems
